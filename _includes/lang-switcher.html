{%- comment -%} MVP language switcher: links to each language's homepage, not a true per-page translation link. Polyglot's `page.ref` mechanism is needed for exact page-to-page switching — swap this include for that once precise cross-page translation links matter. IMPORTANT: Polyglot post-processes the rendered page and rewrites every root-relative href="/..." to the CURRENT page's language (its "automatic URL relativization" feature — normally exactly what you want, so template authors don't have to localize every link by hand). That's wrong here on purpose: a language switcher's whole job is linking to a DIFFERENT language. The leading space right after the opening quote (href=" /...") defeats Polyglot's rewrite regex while staying a normal working link (browsers trim leading whitespace from href values) — this is Polyglot's own documented escape hatch: https://github.com/untra/polyglot#preventing-automatic-relativization {%- endcomment -%}
